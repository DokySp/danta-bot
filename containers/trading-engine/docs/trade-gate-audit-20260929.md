## 검증 범위

회귀검사는 네트워크가 차단된 컨테이너, 합성 계좌와 임시 DB로 수행한다. 실제 주문은 보내지 않는다. 설정 재해석 비용은 같은 로컬 환경에서 50회 중앙값 약 29.0ms에서 2.9ms로 줄었다. NAS의 전체 시세 지연이 같은 비율로 줄었다는 의미는 아니다.

이미지 게시와 NAS에서의 실행 버전 변경은 별개다. 실제 운영 결과는 새 이미지 활성화 후 별도 확인이 필요하다.
